# Data Structures and Algorithms Portfolio

## About

This portfolio contains my C++ Data Structures and Algorithms (DSA) Hands-on Activities (HOAs) from the PRELIM, MIDTERM, and FINALS periods. It is organized according to the different activities and their corresponding requirements, including source codes and other necessary files. This GitHub portfolio serves as a collection of my completed coursework and provides an organized view of the programming tasks I worked on during the course.

## Tools and Technologies
The following tools and technologies were used in completing and organizing the activities:

- **C++** — Main programming language used to implement the data structures and algorithms.
- **C++ Standard Library** — Used for different programming features such as vectors, queues, stacks, threads, and other standard functions.
- **C++ Compiler** — Used to compile and execute the C++ source codes.
- **GitHub** — Used to store, organize, and present the portfolio and its documentation.
- **Markdown** — Used to create the README files for each activity and the main portfolio.

## Topics Covered
- Fundamental C++ Programming and Object-Oriented Programming
- Arrays, Pointers, and Dynamic Memory Allocation
- Linked Lists, Stacks, and Queues
- Searching and Sorting Algorithms
- Trees and Graphs
- Algorithm Analysis and Complexity
- Algorithmic Strategies and Dynamic Programming
- Parallel Algorithms and Multithreading
