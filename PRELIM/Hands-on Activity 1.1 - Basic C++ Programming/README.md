# Hands-on Activity 1.1 — Basic C++ Programming

## Description

This activity focuses on the fundamentals of C++ programming and object-oriented programming. It demonstrates the basic structure of a C++ program, the use of functions, class definitions, and object instances. The activity also includes supplementary programming problems involving mathematical operations and triangle calculations.

## Objectives

- Implement basic programming and object-oriented programming concepts in C++.
- Create code that follows the basic C++ program structure.
- Implement appropriate class definitions and instances based on given requirements.
- Solve different problems using the C++ programming language.

## Implementation

### ILO A — Basic C++ Code Structure

The program demonstrates the use of function prototypes and function definitions placed after the `main()` function. It includes functions for calculating the sum of two numbers, comparing two variables, and displaying the results of logical operations using Boolean values.

### ILO B — Class Definition and Object Instances

The program implements a `Triangle` class that stores three angles and their total. It includes a constructor for initializing the angles, a `setAngles()` method for modifying them, and a `validateTriangle()` method for checking whether the given angles form a valid triangle according to the implemented condition.

### ILO C — Supplementary Activities

The supplementary programs apply C++ programming concepts to different problems:

- **Task 1 — Swapping Two Numbers:** Uses a function with reference parameters to exchange the values of two variables.
- **Task 2 — Kelvin to Fahrenheit Conversion:** Uses a conversion function to calculate the temperature in Fahrenheit from a Kelvin input.
- **Task 3 — Distance Between Two Points:** Uses the distance formula to calculate the distance between two points in a coordinate plane.
- **Task 4 — Triangle Calculator:** Uses a `Triangle` class and mathematical formulas to calculate the area, perimeter, and type of a triangle based on its angles and a given side.

3. Compile and run the program.
